# Niche Overlap in Doñana National Park

## Overview

This repository contains the R scripts and code used to analyze the spatial, temporal, and spatiotemporal niche overlap between the mesocarnivore mammal community (predators) and leporid species (prey) in Doñana National Park using camera trap data.

The analysis is divided into three main components: spatial overlap using Pianka's index, temporal activity patterns using kernel density estimation, and spatiotemporal interactions using recurrent event analysis.

## Repository Structure

- `data/`: Contains the input datasets.
- `scripts/`: R scripts for performing the analyses.
- `results/`: Output files, figures, and tables generated by the scripts.
- `RData/`: Saved R workspace images for quick loading of processed data.

## Scripts Description

### 1. Spatial Analysis

**File:** `scripts/01_spatial_analysis.R`

Calculates the spatial overlap between predator and prey species using **Pianka's Index**.

- Generates a site x species frequency matrix.
- Computes the proportion of activity for each species at each site.
- Calculates Pianka's index for all predator-prey pairs to assess spatial sharing of the habitat.

### 2. Temporal Analysis

**File:** `scripts/02_temporal_analysis.R`

Analyzes the temporal activity patterns and overlap.

- Converts camera trap timestamps to **anchored solar time** (relative to sunrise and sunset) to account for seasonal variation in daylight.
- Fits **circular kernel density estimates** for each species.
- Calculates the **coefficient of overlap (Dhat)** (Dhat1 or Dhat4 depending on sample size) for predator-prey pairs.
- Estimates confidence intervals using bootstrapping.
- Generates activity pattern plots.

### 3. Spatiotemporal Analysis

**File:** `scripts/03_spatiotemporal_analysis.R`

Performs a fine-scale spatiotemporal analysis using the **recurrent event framework** (Ferry et al., 2024).

- Models species detections as recurrent events.
- Tests the effect of a primary species (e.g., predator) on the detection hazard of a secondary species (e.g., prey), and vice-versa.
- Uses **Piece-wise Additive Mixed Models (PAMMs)** to assess attraction or avoidance patterns over time.
- Includes human detections as a tertiary species to control for field maintenance disturbances.

### 4. Diel Phenotypes (Appendix)

**File:** `scripts/Appendix 1 - Diel phenotypes.R`

Classifies species into diel activity phenotypes (e.g., Diurnal, Nocturnal, Crepuscular, Cathemeral).

- Uses a **Bayesian model-based hypothesis testing framework** (Gerber et al., 2024).
- Classifies detections into twilight, day, and night periods based on solar position.
- Compares seven alternative diel activity models and calculates posterior probabilities for each hypothesis.
